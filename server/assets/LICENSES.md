# Motion Pack asset licenses (`server/assets/`)

All files in `lottie/` and `sfx/` are **original procedural works authored for
this project** (generators: `tools/lottie/make.mjs`, `tools/sfx/make.mjs`).
No third-party downloads, no accounts, no attribution requirements.

- `lottie/*.json` — hand-built Lottie shape animations (rect/ellipse/path/trim
  primitives only; no embedded images, fonts, or expressions).
- `sfx/*.wav` — ffmpeg-synthesized sweeps and tones (sine/noise sources only).

Released under **CC0 1.0 Universal**: free for commercial use in videos,
including client work. Regenerate at any time with the scripts above; the
builders address library files by name and content-hash, so regenerated
identical output keeps identical asset IDs.
